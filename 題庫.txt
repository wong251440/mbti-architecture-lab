# DCA Engine v1 題庫規格目錄
* **Module A｜48 行為證據題 (Behavioral Evidence)**：24 Facets × 2 題
* **Module B｜12 強制認知交易題 (Forced Cognitive Trade-offs)**：4 軸 × 3 題
* **Module C｜12 認知微型模擬題 (Micro-Simulations)**：4 軸 × 3 題（每題二階段 Step 1 行為 ＋ Step 2 動機）
* **Module D｜8 認知成本與耗能題 (Cognitive Cost / Recovery)**：8 個極向 × 1 題
* **Diagnostic Probes｜8 動態自適應診斷題**：4 軸 × 2 題

## Module A｜48 行為證據題 (Behavioral Evidence)

> **作答量尺（全 Module A 統一）**：
> * `[NA]` 不適用 / 無相關經驗（不計入分母與平均）
> * `[0]` 幾乎沒有（0 分）
> * `[1]` 少數情況（1 分）
> * `[2]` 約一半情況（2 分）
> * `[3]` 多數情況（3 分）
> * `[4]` 幾乎每次（4 分）
>
> **計分轉換**：$\text{Facet 分數} = \frac{\text{總得分}}{\text{有效作答題數} \times 4} \times 100$

## 系統整合與後端實作指引 (Engine Handover Spec)

### 1. 模組分數計算法則 (Deterministic Scoring Pipeline)

```python
# 1. Module A: 24 Facet Scores (0-100)
for facet in ALL_24_FACETS:
    valid_items = get_answered_items(module="A", facet=facet)  # Exclude 'NA'
    if valid_items:
        raw_avg = sum(item.score for item in valid_items) / len(valid_items)
        facet_scores[facet] = (raw_avg / 4.0) * 100
    else:
        facet_scores[facet] = 50.0  # Fallback default

# 2. 8 Pole Scores (0-100)
E_score = (facet_scores["E1"] + facet_scores["E2"] + facet_scores["E3"]) / 3.0
I_score = (facet_scores["I1"] + facet_scores["I2"] + facet_scores["I3"]) / 3.0
# ... Repeat for S, N, T, F, J, P

# 3. Behavioral Contrasts (-1.0 to +1.0)
B_EI = (E_score - I_score) / 100.0
B_SN = (S_score - N_score) / 100.0
B_TF = (T_score - F_score) / 100.0
B_JP = (J_score - P_score) / 100.0

# 4. Module B: Forced Choice Contrasts (-1.0 to +1.0)
FC_EI = sum(item.score for item in module_B_EI) / (3 * 2.0)
FC_SN = sum(item.score for item in module_B_SN) / (3 * 2.0)
FC_TF = sum(item.score for item in module_B_TF) / (3 * 2.0)
FC_JP = sum(item.score for item in module_B_JP) / (3 * 2.0)

# 5. Module C: Scenario Contrasts & 8 Cognitive Function Accumulation
# Step 1 gives 2 points to the chosen cognitive function indicator
# Step 2 gives 1 point to the chosen cognitive function indicator / primary facet
for scenario in module_C_items:
    cog_funcs[scenario.step1.function_tag] += 2
    cog_funcs[scenario.step2.function_tag] += 1

# 6. Final Axis Scores (Transparent Fixed Weights)
Axis_EI = 0.50 * B_EI + 0.30 * FC_EI + 0.20 * SC_EI
Axis_SN = 0.50 * B_SN + 0.30 * FC_SN + 0.20 * SC_SN
Axis_TF = 0.50 * B_TF + 0.30 * FC_TF + 0.20 * SC_TF
Axis_JP = 0.50 * B_JP + 0.30 * FC_JP + 0.20 * SC_JP
```

### 2. MBTI Best-fit 與 Precision Type 判定規則

* **Best-fit Type**：
  * 若 $\text{Axis} \le 0$，取第一字母（E, S, T, J）；若 $\text{Axis} > 0$，取第二字母（I, N, F, P）。
* **Precision Type**：
  * 若 $|\text{Axis}| < 0.15$，該維度以 `X` 標記（例如：`Axis_TF = 0.08` $\rightarrow$ `ENXP`）。
  * 同時在報告中標註 `T/F currently balanced / Dual-High`。

### 3. Adaptive Probes 觸發條件（最大題數 88 題）

probes_to_trigger = []

    # Condition 3: Contextual Shift (Baseline vs Pressure)
    if abs(baseline_scores[axis] - pressure_scores[axis]) > 0.40:
        probes_to_trigger.extend(get_probes(axis, count=2))
